LINGUO KARTIČKY

RYCHLÉ SPUŠTĚNÍ NA PC:
1. Ve složce spusťte: python -m http.server 8000
2. Otevřete: http://localhost:8000

MOBIL / INSTALACE:
Nahrajte celý obsah složky na libovolný HTTPS webhosting (GitHub Pages, Netlify, vlastní HTTPS server). Otevřete adresu v telefonu a zvolte Přidat na plochu / Nainstalovat aplikaci.

Data se ukládají lokálně v prohlížeči. Pro přenos používejte zálohu JSON nebo CSV.
